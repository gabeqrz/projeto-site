## 📋 Sobre o projeto

A Raw Foodstore simula uma loja de refeições vegetarianas prontas, com uma vitrine de produtos e uma página dedicada aos detalhes de um prato.

O projeto foi desenvolvido para praticar os fundamentos do front-end, explorando estrutura semântica, organização do CSS, layouts responsivos e recursos de acessibilidade, sem depender de JavaScript nesta etapa.

### 🎨 Referência visual

O ponto de partida foi o template [Shopify Product Catalog, da Lovable](https://lovable.dev/templates/websites/ecommerce/raw-goods-shopify-storefront), utilizado como referência visual. A interface foi adaptada e implementada com HTML e CSS em um repositório próprio no GitHub, com publicação pelo GitHub Pages.

## ✨ Funcionalidades implementadas

- **Vitrine de produtos:** apresentação de nove refeições vegetarianas.
- **Página de produto:** descrição, preço e informações complementares.
- **Informações nutricionais:** tabela com dados do produto.
- **Conteúdo expansível:** seções de ingredientes, conservação e preparo com HTML nativo.
- **Navegação por âncoras:** acesso às principais seções da página.
- **Identidade visual:** paleta de cores, tipografia e componentes consistentes.
- **Acessibilidade:** HTML semântico, textos alternativos, link para pular ao conteúdo e indicadores de foco para navegação por teclado.

## 🧪 Resultados e validação

Durante o desenvolvimento, foram trabalhados aspectos de semântica HTML, organização do CSS, responsividade e acessibilidade. O HTML foi validado com o **W3C Validator**, sem erros na validação realizada. A validação pelo Lighthouse ainda está pendente.

O projeto está publicado no GitHub Pages, permitindo visualizar a interface e consultar o código-fonte no repositório.

## 🚧 Limitações atuais

Como a proposta desta etapa é trabalhar com HTML e CSS, algumas interações ainda são apenas visuais:

- Busca, filtros por categoria e carrinho não estão funcionais.
- Os botões de compra não processam pedidos.
- O formulário ainda não possui um fluxo completo de envio.
- Apenas um produto possui página própria de detalhes.
